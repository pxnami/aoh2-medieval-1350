# Medieval1350_14K

Extract this folder into the game's `mods` directory, restart the game, select **Earth14K**, and choose **1350 - The Medieval World (14K)**. Start a new campaign.

If the combined `Mittelalter1350` package is already installed, move it out of the mods directory first to avoid overlapping overrides.

Complete features, event effects, historical sources, limitations and validation are available in the [GitHub README](https://github.com/pxnami/aoh2-medieval-1350#readme).

Requires Age of History 2: Definitive Edition and the game's original map files.
